## 1. 対象と利用目的

Kakeibow（以下「本サービス」）は、収支・予算・決済方法・支払い予定・割り勘などを管理する家計簿です。運営者は、以下の情報を、本人認証、家計簿の保存・同期・集計、入力補助、本人が選んだ共有・通知、不正利用防止、お問い合わせへの対応に必要な範囲で取り扱います。

## 3. Gmail連携（任意）

### 権限と取得範囲

Gmail連携は通常のGoogleログインとは別です。利用者が対象Googleアカウントを選び、Googleの同意画面で許可した場合にだけ接続します。利用しなくても手入力などを利用できます。接続だけではAIによるメール検出は始まりません。アプリ内の新しい説明に同意し、AI明細検出を有効にした後に限り処理します。従来の4項目を対象としたAI同意や旧設定は、新しい送信内容・対象範囲への同意として扱いません。

要求する `gmail.readonly` は、権限としてはGmail全体のメール等を読み取れる範囲です。特定のカード会社・銀行だけに限定するGoogle権限ではありません。AI明細検出を有効にした場合、本サービスは同意後に受信した新しいメールから、差出人を限定せず、金融取引に関する件名語句でカード・銀行・電子マネー等の明細候補を探します。過去メールを一括してAI解析する機能ではありません。迷惑メール・ゴミ箱は検索対象外です。メール送信・削除・既読変更、添付ファイルの取得、本文中のリンクやリモート画像へのアクセスは行いません。

候補を調べる最初の段階では件名、差出人、認証結果などのヘッダー情報を確認します。DMARCで送信元ドメインが厳密に一致し、件名条件も満たすメールに絞り、メール全体の推定サイズが256KiB以下の場合に本文を確認します。テキスト・HTMLのデコード量は64,000バイトまでとし、上限を超えるメールや未対応の文字コードは解析対象外になる場合があります。添付ファイル、本文のリンク先、リモート画像は取得しません。これらは候補を絞るための確認であり、送信元やメールの真正性を完全に保証するものではありません。

サーバー稼働中、おおむね5分ごとに確認します。停止・通信障害・取得件数などにより遅れることがあります。過去のメールをすべて遡って取得する機能ではありません。

### 解析・保存

取得したメール本文・ヘッダーは処理時に一時的に扱い、元メール本文をデータベースや処理ログに保存しません。AI判定では必要な範囲を正規化し、本文は最大6,000文字、件名は最大300文字に制限して、氏名・住所・口座番号・カード番号・カード末尾・認証ID・URL・メールアドレス等を可能な範囲で除去します。送信するのは加工した件名と判定に必要な本文部分だけで、差出人アドレス、プロフィール情報、メール識別子などを独立した入力項目として付加しません。ただし、除去しきれない個人情報が残る場合や、店名・日時・金額等から個人や取引を推測できる場合があり、匿名化は完全ではありません。

AIは利用・銀行入出金・請求・チャージ・返金等を分類し、金額や日時に根拠があるか確認して候補を作ります。項目が不足する場合や確認が必要な候補もあり、銀行入出金・請求・チャージ・返金等は確認専用で、支出入力には進みません。すべてのメールを認識できる保証、または正規の発行元・メールであることを完全に判定する保証はありません。候補は利用者が原本と照合して確認するためのもので、家計簿へ自動登録しません。

接続用の更新トークン、接続途中のトークン、未確認候補はアプリ側の鍵で暗号化してサーバーに保存します。連携先アドレスはマスクした形で保存します。メール識別子はハッシュ化して重複確認に利用します。家計簿へ保存された通常の明細まで同じ方式で暗号化される、という意味ではありません。

未処理候補は作成から30日を超えると定期削除の対象になり、取込済み・破棄済み候補は操作時に候補本文を消去します。処理失敗は最大3回試行し、その後はメール本文を保持せずハッシュだけの失敗記録を残します。処理用ハッシュ等は作成から90日を超えると削除の対象になり、サービス全体の集計値は7日を超えると削除の対象になります。AIの試行上限は既定で1利用者あたりUTC日次20回、全利用者合計200回で、失敗した試行も上限に含みます。これらの上限は運用上変更される場合があります。定期削除はサーバー稼働に依存するため、停止中も指定時刻どおりに消去されるとは限りません。

### 停止・解除

「自動確認を停止」は新しい確認を止めますが、接続情報や既存候補は残ります。「Gmail連携を解除」は本サービス上の接続情報・候補・接続途中情報を削除し、Googleへの権限取消も試みます。Google側の取消に失敗した場合は、Googleアカウントの接続済みアプリ設定から解除してください。

解除しても、すでに本人が家計簿へ保存した明細やGoogle上の元メールは消えません。家計簿の明細は別途削除できます。

### Googleデータの利用制限

Google Workspace APIから取得した情報とその派生データは、本人に示した家計簿の入力補助・取引候補の確認・通知に限定して利用します。販売、広告配信、信用評価、汎用AIモデルの学習には利用しません。人がメール内容を読む運用は行わず、個別の明示的同意に基づくサポート、不正利用・安全性の調査、法令対応など、Googleのポリシーが認める場合に限ります。

本サービスによるGoogle APIから受け取った情報の利用および他のアプリへの転送は、[Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy)および[Google Workspace User Data and Developer Policy](https://developers.google.com/workspace/workspace-api-user-data-developer-policy)のLimited Use要件を遵守します。

Gmail連携の一般向け正式提供は、必要な設定・安全管理・Googleの審査等の確認後に行います。接続機能の試験提供や本ポリシーの公開は、Google審査の申請・承認や安全性評価の完了を意味しません。

## 4. AIへの送信（任意）

AI入力補助にはOpenAI APIを使用します。目的と送信内容を確認したうえで利用してください。

- レシートAI：選択したレシート画像全体と登録済み品目名を送信し、題名・日時・金額・品目・決済方法等の候補を取得します。画像内に写る氏名・住所・会員番号等も送信され得るため、不要な部分は送信前に隠してください。アプリ側は画像を家計簿DBや入力下書きへ保存する設計ではありません。
- GmailのAI明細検出：接続とは別に、本人がアプリ内の新しい説明を確認して同意・有効化した後に限り、同意後に届く新着メールから明細候補を探します。対象は三井住友を含むカード・銀行・電子マネーなどのメールです。従来のAI設定・同意は新しい対象範囲や送信項目への同意として引き継ぎません。件名（最大300文字）と、正規化・可能な範囲で個人情報を除去した必要本文部分（最大6,000文字）だけをOpenAIへ送ります。差出人アドレス、プロフィール情報、メール識別子などを独立した入力項目として付加せず、本文中のカード番号・末尾等も可能な範囲で除去します。匿名化は完全ではなく、除去しきれない情報が残る場合があります。添付ファイルを取得したり、リンク先やリモート画像を開いて送信する処理はありません。誤判定や候補の見落としがあり、候補は自動で家計簿へ登録されず、確認してから保存できます。

両機能は結果の保存を抑える `store=false` を指定しますが、OpenAI側の一切の保持をなくす設定ではありません。不正利用監視などに伴う保持・例外は、契約設定と[OpenAIのデータ管理説明](https://developers.openai.com/api/docs/guides/your-data)に従います。Gmail連携の提供にあたっては、Google取得データを汎用モデルの学習に共有しない設定を確認し、その利用制限を維持します。

AIは誤認識したり、候補を見落としたりする場合があります。送信元・認証結果の確認も完全ではありません。保存前に原本・カード会社等の公式明細と照合してください。Gmail AI明細検出の同意は設定から取り消せますが、すでに外部へ送信した情報の保持を遡って取り消す保証はありません。`store=false` はOpenAI側のゼロ保持を意味しません。

## 5. 共有・外部サービス

- 割り勘：相手への新規共有は招待・承認後に行います。移行前の既存共有は維持されている場合があります。相手には共有元のアカウント名・識別子と、割り当てた負担合計・清算額・残額を表示し、家計簿全体や口座残高を公開するものではありません。共有停止後も相手が保持する記録や以前の表示・コピーまで消去できるとは限りません。
- 通知：対応ブラウザー・OSの許可後、Google・Mozilla・Apple等のPush配信サービスを介して通知します。Gmail候補通知の文面には店名・金額・メールアドレス・カード情報を含めません。配信済み・表示済み通知の消去は保証しません。
- 通信・認証・メール：公開通信の中継にCloudflare、本人が選んだ外部認証にGoogle・LINE、確認コード等の送信に設定済みメール配信サービスを利用します。各提供先は、その処理に必要な通信情報・認証情報・宛先等を扱います。AI送信は第4項の範囲です。

外部提供先による処理・保存が日本国外で行われる場合があります。取り扱いは各提供先の条件・契約設定にも依存します。国外への提供等について適用法令上の説明や同意が必要な場合は、その手続きを行います。取り扱いについては問い合わせ窓口へご相談ください。法令に基づく提供が必要な場合も、適用法令に従って対応します。

## 6. Android通知取り込み（試験機能・任意）

Android試験版では、別途説明・同意とOSの通知アクセス許可を得た場合、三井住友銀行・Vpassの取引通知を取り込みます。端末内で対象アプリと取引内容を絞り、保留データを暗号化して最大50件・7日間保管し、アクセス時に期限切れを整理します。通知取得部分から直接ネットワークへ送る機能はありません。アプリで取り込んで確認・保存した家計簿項目は通常の同期対象です。取り込みを無効にすると保留データと鍵を削除します。OSの許可も設定から解除できます。

## 7. 端末保存・安全管理・保持

オフライン利用のため、家計簿や下書き・表示設定等を端末のIndexedDB・localStorage等に保存し、PWAの表示用ファイルをキャッシュします。ログイン状態の管理にはCookie等を利用します。端末を共有するときはログアウトし、端末自体も保護してください。

ログインして同期したデータは運営者管理のサーバーにも保存します。通信のHTTPS、パスワードのハッシュ化、認証・アクセス制御、一部の連携情報の暗号化等を用いますが、全情報の端末間暗号化や、すべての保存領域の暗号化を保証するものではありません。

通常の家計簿記録は、利用者が削除するまで保持します。明細削除は同期のため削除状態の記録が残ることがあり、アカウント削除と同一ではありません。アクセスログには現在、自動削除の固定期限を設けていません。利用目的に照らして保持の必要性を見直し、取り扱いに関する相談を窓口で受け付けます。

災害・障害復旧用のバックアップには削除前のデータが残る場合があります。通常の定期バックアップはスクリプト上30日を目安に世代管理しますが、手動保存したバックアップや停止中の処理まで同じ期限で消去されることを保証するものではありません。バックアップの削除に関する相談も窓口で受け付けます。

## 8. 確認・訂正・削除・お問い合わせ

設定からプロフィール、メール認証・変更、外部連携、通知設定を管理できます。家計簿記録は編集・削除でき、JSON・CSVによる書き出し機能があります。

アカウント削除には本人確認が必要です。サーバー上の本人のアカウント・同期データ・Gmail連携情報・候補・通知購読等を削除し、操作端末の家計簿データ等を消去します。ただし、未接続の別端末、利用者が出力したファイル、相手側の割り勘記録、バックアップ、外部サービスの保有情報まで即時に消去するものではありません。アカウント削除だけでGoogle側の権限取消が完了する保証もないため、Googleアカウント側の連携設定も確認してください。

開示・訂正・利用停止・削除等の相談は冒頭の窓口へご連絡ください。運営者が受け付け、ご相談内容と対象アカウントを確認し、適用法令と情報の保有状況に応じて回答・対応します。本人の情報に関する請求では、登録メールアドレス等により必要な範囲で本人確認を行い、必要な手続きや対応できない理由がある場合は個別に案内します。パスワード・確認コード・APIキーを問い合わせメールに記載しないでください。
