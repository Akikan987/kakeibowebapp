## データ互換性

品目の同期形式は従来の名前文字列のまま。既存ユーザーへ新しい初期品目を一括追加しない。新規端末のゲスト初期値は、既存アカウントへ初めてログインする際、未変更かつ未使用のものだけを除外する。ゲストで記録した明細や使用した品目、改名、削除情報は残す。新規登録の場合だけ不足する初期値を追加する。

電話番号の移行は `users` と `pending_registrations` の `NOT NULL` を外す。既存値・一意インデックスは維持する。APIレスポンスの未登録電話番号は空文字にして旧クライアントと互換性を保つ。移行時は短いテーブルロックが発生しうる。電話番号なしの登録後に `NOT NULL` を戻す単純なロールバックは行わない。

## 検証

- Webの単体テスト204件、TypeScriptを含むビルド、法務ページ・紹介ページ・配布APK検査が成功。
- APIは本番と別のPostgreSQLで270件成功。電話番号なしの複数登録、従来の電話ログイン、一意性、旧NOT NULLスキーマからの繰り返し移行を含む。
- 隔離したブラウザーに架空の収支・カード・予算・割り勘を投入。375px／1024px、ライト／ダークで横あふれ、タブ切り替え、データ管理への移動、紹介ページを確認。実画面画像の撮影は390px×820px、2倍解像度。
- 日付選択とカード明細、グラフの日付移動、凡例、定期項目の必須エラーとフォーカス、収入品目、予算の削除対象、999,999,999円の入力、タイトルからの連続選択、確認なしの破棄を確認。
- PWA更新は以前の指示を維持し、開いている全画面を閉じた後で新版に切り替える。編集途中の強制再読み込みや更新通知を追加しない。
- 本番イメージの入口HTMLが直接参照するJSを同じgzip条件で比較し、250,119→253,051バイト（約1.2%増）。追加の画面は引き続き分割し、初回描画後に先読みする。
- package.jsonにはlintコマンドがないため、lint合格とは扱わない。

## 実装以外に残る確認

Cloudflareのアクセス解析を利用するか停止するかは運営者の選択が必要。設定は変更していない。端末実機でのキーボード・Android/iPhoneのsafe area・戻るジェスチャーは、今回のブラウザー検証だけでは保証しない。GoogleのGmail審査や第三者評価の完了を意味しない。
